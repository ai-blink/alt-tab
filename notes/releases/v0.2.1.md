# Switchboard v0.2.1 Portable

Switchboard의 앱 아이콘을 정리하는 Windows 11 x64 Portable 패치 릴리즈입니다.

## 변경 사항

- 네 개의 창과 양방향 전환 화살표를 표현한 새 Switchboard 아이콘을 추가했습니다.
- 짙은 차콜 아이콘 타일 바깥을 알파 투명으로 처리했습니다.
- 트레이, 작업 표시줄 창, 실행 파일이 같은 다중 해상도 Windows 아이콘을 사용하도록 통일했습니다.

## 검증

- Release 빌드: 경고 0개, 오류 0개
- 테스트: 41/41 통과
- 자체 포함 Windows 11 x64 단일 실행 파일 패키지 확인
