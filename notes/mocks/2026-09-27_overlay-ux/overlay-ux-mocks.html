Switchboard 오버레이 UX 비교 목업 — 아이콘·라벨 / 툴바 / 카드 표시

현재 스크린샷(24개 창)에서 관찰된 문제 3가지를 각각 섹션으로 나눠, 현재 상태(CURRENT)와 2~3개 변형안(A/B/C)을 나란히 비교합니다.

이 페이지는 아무것도 결정하지 않습니다. 세 섹션 모두 사용자가 눈으로 보고 직접 고르는 용도이며, 아래 "선택 결과" 라디오는 고른 값을 문자열로만 정리해 줄 뿐 채택 여부를 판단하지 않습니다.
미리보기 배경: (참고용 — 카드/툴바 자체 색은 프로젝트 다크 팔레트를 그대로 씀)

섹션 1 — 앱 아이콘 · 라벨 현재 + A/B/C

현재 문제: 카드에 앱 아이콘이 없고, 캡션이 "앱이름(8자 절단) + 제목"이라 "Hermes Hermes", "ChatGPT ChatGPT"처럼 같은 말이 반복되거나 "MiniCap…", "Everythi…"처럼 잘려서 무슨 앱인지 알아보기 어렵습니다.
체크포인트: 아이콘만 보고 앱을 바로 알아볼 수 있는지, 이름이 중복될 때 각 변형이 자연스럽게 처리하는지, 카드 폭이 좁아도 제목이 충분히 보이는지를 비교하세요.
CURRENT아이콘 없음 · 이름+제목 항상 표시

아이콘 없이 "앱이름(절단) + 제목"을 항상 나란히 표시 → 중복·절단 문제 그대로 재현.

A아이콘 + 제목만, 앱이름은 툴팁

캡션엔 제목만 크게 표시. 앱이름은 카드에 마우스를 올렸을 때 툴팁으로만 노출 (카드에 title 속성 적용).

B아이콘 + 제목, 다를 때만 앱이름 2줄

제목이 1줄, 앱이름은 제목과 다를 때만 작은 2번째 줄로 추가 표시(중복 자동 제거).

C큰 아이콘을 썸네일 모서리에 overlay

아이콘을 썸네일 좌하단에 크게 겹쳐 표시하고, 캡션엔 제목만 남김.

섹션 2 — 툴바 간소화 현재 + A/B

현재 문제: 검색창에 placeholder가 없고, 보기/테마/정렬 3개 세그먼트 + 아이콘 버튼 4개가 한 줄에 몰려 있으며, 선택된 세그먼트 텍스트(예: 라이트, 즐겨찾기)의 대비가 매우 낮아 어떤 게 선택됐는지 읽기 어렵습니다.
체크포인트: 선택된 세그먼트 글자가 확실히 읽히는지, 자주 안 쓰는 테마 전환이 툴바에서 빠져도 불편하지 않은지, 검색창에 placeholder가 생겨 첫 화면에서 무엇을 입력할 수 있는지 바로 아는지 비교하세요.
CURRENT검색 placeholder 없음 · 3단 세그먼트 · 저대비 선택

검색창에 안내 문구가 없고, 보기/테마/정렬 세그먼트가 모두 노출되며 선택 항목 글자가 흐릿합니다.

섹션 3 — 카드 표시 현재 + A/B/C

현재 문제: 선택 표시가 얇은 파란 테두리뿐이라 눈에 잘 안 띄고, 24개 카드 전부에 닫기(X) 버튼이 항상 떠 있어 오클릭 위험이 크며, 반투명 배경 때문에 뒤에 있는 다른 창의 글자가 카드 사이로 비쳐 보입니다. 아래 4개 패널은 모두 같은 "번잡한 가짜 배경" 위에 올려 비침 정도를 비교할 수 있게 했습니다.
체크포인트: 선택된 카드(작업 관리자)가 한눈에 띄는지, 닫기 버튼이 실수로 눌릴 만큼 자주 보이는지, 카드/여백 사이로 뒤 글자가 얼마나 비치는지(특히 C)를 비교하세요.
CURRENT얇은 테두리 선택 · X 항상 표시 · 반투명

선택 카드가 1px 파란 테두리뿐이라 잘 안 보이고, 모든 카드에 X가 항상 떠 있으며 배경 글자가 비칩니다.

A두꺼운 강조 링 + 살짝 들뜨는 효과, X는 호버 시만

선택 카드에 두꺼운 파란 링과 그림자로 확실히 띄우고, 닫기(X)는 마우스를 올리거나 선택된 카드에서만 나타남.

B선택 시 캡션 바를 강조색으로 채움, X는 호버 시만

테두리 대신 캡션 바 배경 전체를 강조색으로 채워 선택을 표시. 닫기(X)는 A와 동일하게 호버 시만.

C선택 스타일은 A와 동일 + 배경을 더 불투명하게(아크릴)

선택/닫기 동작은 A와 같고, 패널과 카드 배경 불투명도를 크게 올리고 블러를 더해 뒤 글자 비침을 크게 줄임 — 같은 배경 위 CURRENT와 직접 비교.
