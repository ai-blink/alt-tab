① 글씨와 버튼을 먼저 지키는 안

작음

창 크기와 UI 크기를 분리합니다. 창은 작아져도 글씨와 버튼은 작아지지 않습니다.

추천안: 위치를 정하고, 창 크기와 UI 크기를 같은 5단계로 고릅니다. 열과 행은 자동으로 맞춥니다.
용어창 크기 = 화면에서 차지하는 영역UI 크기 = 글씨·버튼·여백자동 배치 = 남는 공간에 맞춰 카드 수를 정함

창 크기

UI 크기 크게

글씨와 버튼을 크게 유지합니다.

🔧 개발 연결 메모
현재 SelectedOverlayScalePreset은 창과 UI를 함께 줄입니다. 이 안은 창 한도와 UI 배율을 별도 설정으로 분리하고, 행·열은 기존 자동 배치 계산을 유지합니다.

② 보이는 카드 수까지 직접 고르는 안

중간

창 크기와 UI 크기를 분리한 뒤, 한 화면에 보일 최대 열·행도 직접 고릅니다.

배치를 고를 수 있습니다. 많이 보고 싶을 때는 열·행을 늘리고, 조작을 편하게 하려면 2열·2행처럼 줄입니다. 넘는 창은 아래로 스크롤합니다.
