# 컴팩트 창 설정 목업

- 현황: 현재 앱의 `전체 배율`은 창과 UI를 함께 축소하며, 컴팩트 창은 위치 선택만 제공한다.
- 목업: 글씨 우선, 배치 조절, 빠른 선택의 세 탭을 한 HTML에서 조작·비교하도록 구성했다. 1안은 창 크기와 UI 크기를 같은 5단계 선택으로 통일했고, 2안은 창 크기 조절을 제거해 UI 크기·열·행으로 창 크기를 자동 계산한다.
- 결정: 사용자가 1안을 확정했다. 컴팩트 모드는 위치 선택, 다섯 단계의 창 크기, 다섯 단계의 독립 UI 크기, 자동 카드 배치를 제공한다.
- 범위: 2안의 최대 행·열 수 조절과 3안의 프리셋은 구현하지 않는다. 현재 70% 통합 축소 프로토타입은 다음 구현 슬라이스에서 확정안으로 교체한다.
- 검증: `dotnet build Switchboard.slnx -c Release --nologo` 경고·오류 0개, `dotnet test Switchboard.slnx -c Release --nologo` 19개 통과, 목업 inline JavaScript 문법 검사 통과.
