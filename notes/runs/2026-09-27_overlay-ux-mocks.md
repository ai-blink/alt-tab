# 2026-09-27 오버레이 UX 비교 목업

산출물: `notes/mocks/2026-09-27_overlay-ux/overlay-ux-mocks.html` (자기완결 단일 HTML, 외부 네트워크 자산 없음)

## 구성 (현재 + 변형안, 사용자 육안 선택용 — LLM 확정 없음)
- **섹션 1 · 아이콘·라벨**: CURRENT(아이콘 없음, "앱이름 8자 절단 + 제목" 항상 표시·중복 재현) / A(아이콘+제목만, 앱이름은 툴팁) / B(아이콘+제목, 제목과 다를 때만 앱이름 2번째 줄) / C(큰 아이콘을 썸네일 모서리에 overlay, 캡션엔 제목만)
- **섹션 2 · 툴바 간소화**: CURRENT(검색 placeholder 없음, 보기/테마/정렬 3단 세그먼트, 선택 텍스트 저대비 재현) / A(검색 placeholder 추가, 테마는 설정으로 이동, 정렬은 드롭다운 1개) / B(검색 중심 최소 바 + "보기·정렬" 통합 메뉴 버튼). A·B 모두 선택 세그먼트 고대비로 고정.
- **섹션 3 · 카드 표시**: CURRENT(얇은 테두리 선택, X 항상 노출, 반투명 배경) / A(두꺼운 강조 링+들뜸 효과, X는 호버·선택 시만) / B(선택 시 캡션 바 강조색 채움, X는 호버 시만) / C(선택 스타일은 A와 동일, 배경 불투명도·블러만 대폭 상향). 4개 패널 모두 동일한 가짜 "번잡한 배경" 위에 올려 비침 정도를 직접 비교 가능.

## 하단 선택 도우미
섹션별 라디오 3개 + "선택 결과 복사" 버튼 → `아이콘:B, 툴바:A, 카드:C` 형태 문자열만 클립보드에 복사. **아무것도 대신 결정하지 않음.**

- 외부 `src="http…"` / `href="http…"` 스크립트·리소스 없음 — grep 확인, 0건.
- 이모지 사용 없음(사용자 전역 규칙 준수) — 정규식 스캔 0건.
